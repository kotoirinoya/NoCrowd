# NoCrowd

**テスト期間、「勉強できるカフェ」をもう探し回らない。**

カフェの混雑状況をその場で確認し、席をそのまま予約できる、大学生のための勉強カフェ探しアプリです。

## こんな経験、ありませんか?

- テスト期間、勉強しようとカフェに向かったら満席で入れなかった
- 何軒も回ってやっと座れたときには、もう集中する気力が残っていない
- Wi-Fiや電源があるか、行ってみるまで分からない
- チェーン店以外は長時間居座れるか不安で、結局いつもの店に行ってしまう

NoCrowdは、この「カフェ難民」状態をなくすために作りました。

## NoCrowdでできること

- **混雑状況が地図でひと目で分かる**
  現在地から近いカフェの空席状況を、地図上のマップピンで確認できる
- **その場で座席予約**
  今すぐ座りたいときの即時予約と、時間を決めておく日時指定予約の両方に対応
- **勉強向き設備を事前にチェック**
  Wi-Fi・電源の有無、禁煙かどうかを、行く前に確認できる
- **お店の雰囲気は写真の口コミでわかる**
  実際に利用した人が撮った店内・商品の写真つきレビューを閲覧・投稿できる
- **気に入ったカフェを友達にシェア**
  「ここ空いてるよ」を友達に共有して、一緒に勉強する場所をすぐ決められる

## こんな人におすすめ

- テスト期間、家では集中できず外で勉強したい大学生
- カフェを探す・移動する時間がもったいないと感じている人
- 毎回同じチェーン店に行かず、自分に合う勉強カフェを見つけたい人

## 構成図(開発者向け)

```mermaid
graph LR
    USER[ユーザーのブラウザ]
    VITE["画面<br/>(Vite + React)"]
    API["api/<br/>(Vercel Functions)"]
    DB[("Postgres<br/>(Neon)")]
    OSM["外部サービス<br/>地図タイル (OpenStreetMap)"]
    BLOB["外部サービス<br/>画像保存 (Vercel Blob)"]

    USER -->|操作・入力| VITE
    VITE -->|画面表示| USER
    VITE -->|リクエスト(JSON)| API
    API -->|レスポンス(JSON)| VITE
    API -->|接続・クエリ| DB
    DB -->|結果(JSON化前データ)| API
    VITE -->|タイル取得| OSM
    API -->|画像アップロード| BLOB
    BLOB -->|画像URL| API
```

- ブラウザは Postgres に直接接続せず、必ず `api/`(Vercel Functions)を経由する
- 地図タイル(OpenStreetMap)のみ、APIキー不要のためブラウザから直接取得している
- 画像アップロードは `api/uploads.ts` が受け取り、Vercel Blob に保存してURLだけをブラウザに返す
